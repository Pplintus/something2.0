# 🏐 Volleyball (SFML + C++ + SQLite)

Volleyball — двухпользовательская аркадная игра, вдохновлённая мини-игрой *A Way Out*.
Игроки управляют персонажами, стараясь перекинуть мяч через сетку и победить противника.

---

## 🚀 Возможности

| Функция                          | Описание                                                        |
| -------------------------------- | --------------------------------------------------------------- |
| 🎮 2 игрока локально             | Управление с одной клавиатуры (1P — A/D/W, 2P — ←/→/↑)          |
| 🧠 Реалистичная физика мяча      | Скорость и угол отскока зависят от траектории и действий игрока |
| ⚙ Меню состояний (State Machine) | Главное меню, игра, пауза, настройки                            |
| 🎨 Кастомизация игроков          | Выбор цвета + загрузка текстур через диалог Windows             |
| 🏆 Отображение победы            | После раунда выводится сообщение с результатом                  |

---

## 🛠 Технологии

| Стек                  | Использование                            |
| --------------------- | ---------------------------------------- |
| C++                   | Основная логика игры                     |
| SFML                  | Графика, окно, обработка ввода           |
| Windows API (CommDlg) | Диалог выбора файла при загрузке текстур |


## Требования:
- Windows 7/8/10/11
- Visual Studio 2019 или новее
- Библиотека SFML 2.5.1

## Сборка:
- Скачайте папку `Release` со всеми необходимыми DLL
- Запустите `something2.0.exe`

## 🎮 Управление

| Игрок        | Движение                          |
| ------------ | --------------------------------- |
| P1           | A — влево, D — вправо, W — прыжок |
| P2           | ← — влево, → — вправо, ↑ — прыжок |
| Pause        | Esc                               |
| Выбор в меню | ↑ ↓ + Enter                       |
